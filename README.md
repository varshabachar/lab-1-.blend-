# Blender Lab 1

## Overview

This project contains the Blender work completed for the lab assignment. The tasks demonstrate basic 3D modeling operations including creating primitive objects and transforming them using translation, rotation, and scaling.

## Tasks

### Task 1: Basic 3D Objects and Transformations

Created the following objects in Blender:

* Cube
* Sphere
* Cylinder

Applied the following transformations:

* **Translate** – moved objects along the X, Y, and Z axes.
* **Rotate** – rotated objects around different axes.
* **Scale** – changed the size of the objects along different axes.

### Task 2: Simple Object Using Loop Cut

Created a simple 3D object using **Loop Cut** in Blender.

Loop cuts were used to add additional edge loops to the mesh, allowing the shape and geometry of the object to be modified.
